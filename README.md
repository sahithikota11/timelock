TIMELOCK

Project Goal:

TIMELOCK is a digital time capsule application where users can save personal messages for their future selves. Users can write a message, give their capsule a title, and choose a date when they want to open it.
The idea behind this project is that people often take pictures or write about their experiences but don't always go back and look at them. TIMELOCK gives users a more poignant way to save their thoughts and revisit them at a later point in their lives.

MVP Features:
The first version of TIMELOCK will include:
-Creating a capsule with a title and personal message.
-Saving capsules so they are still available after closing the application.
-Choosing an unlock date for each capsule.
-Keeping capsules locked until their unlock date.
-Viewing all saved capsules and checking whether they are locked or unlocked.
-Opening and reading capsules once they become available.

Future Plans:
In the future, I would like to add:

-Adding photos to capsules.
-Searching and filtering through older capsules.
-Sending email reminders when capsules become available.
-Customizing how capsules look.

These features are not part of the first version, but they could make the application more interesting to use.

Tech Stack:
-Java: Main programming language used to build the application.
-Java Time (`LocalDate`): Used to work with unlock dates.
-Java NIO (`Files` and `Path`): Used to save and read capsule data.
-Java Scanner: Used to track changes and store the project
